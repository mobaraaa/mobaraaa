## Featured Project

### [UK Crime Data Analysis](https://github.com/mobaraaa/uk-crime-data-analysis)

I analysed **1,578,336 recorded incidents** across Merseyside, West Midlands, and West Yorkshire from January 2024 to December 2025.

- Cleaned and prepared the data with PySpark.
- Used Spark SQL to compare monthly trends and identify the areas with the highest recorded counts.
- Visualised the results with pandas and Matplotlib.

The repository includes the analysis notebook, setup instructions, and a summary of the findings.
